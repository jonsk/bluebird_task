> 目的：针对企业级评审 `0305审核_用户需求与操作逻辑_企业级TODO应用.md`，逐维度记录**需求 → 设计覆盖 → 状态 → 设计锚点**，作为「新版是否满足企业级 TODO 要求」的单一对照表，避免重复质疑。

## 4. 明确非目标（本版本）

- 多租户 / 多企业；移动端 / 小程序 / H5；K8s；微服务 / 分布式事务
- 即时通讯 / 审批流 / 消息中心（含评论、活动流、关注订阅）
- 提醒/通知投递（站内信/邮件/企微推送）
- 部门级**写**权限（主管对下属任务仅只读）
- 全文检索引擎 / 高级多条件筛选；任务手动排序
- 按钮级细粒度权限（`sys_permission` 不建，本期仅 `role_code`）
- **密码复杂度/过期策略、附件病毒扫描、存储加密、强制 HTTPS-only**（二期；本期仅登录防暴破 + 安全头）
- **可观测性（Prometheus/Metrics/分布式追踪）、多实例/调度 leader 选举手册**（二期）
- **实时协同（WebSocket/SSE）、审计防篡改（hash 链/WORM）**（二期）
