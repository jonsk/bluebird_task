> 范围：BlueBird `bluebird-task/frontend/`（Vue3 + TS + Element Plus + Tailwind）

> 关联：`src/styles/tokens.css`（`--bb-*` 设计令牌，ADR-009 单制品）、原子契约 `--bb-*` 令牌体系（03 §4.4 / §6）、`stores/app.ts`（03 §4.2）

## 0. 需求

给系统增加**主题功能**：用户可在多套风格主题间**切换**，选择被**持久化**，下次进入自动生效。默认保持现有「经典浅色」视觉（不动其基线，避免破坏前端基线冻结一致性）。

## 1. 现状基础（决定实现方式的前提）

| 现状                                                                   | 含义                                                |
| -------------------------------------------------------------------- | ------------------------------------------------- |
| 颜色全部走 `tokens.css` 的 `:root` 下 `--bb-*` CSS 变量                       | **单一权威源**——多主题只需在作用域覆盖变量即可全局生效                    |
| Tailwind 语义色（`primary/success/danger/overdue/near`）映射到 `var(--bb-*)` | 工具类随主题联动                                          |
| bb 组件、布局、视图均用 `var(--bb-*)`                                          | 组件无需逐个改                                           |
| Element Plus **按需引入**，有独立 `--el-*` 变量体系                              | 需同步映射 `--el-color-*` 以联动按钮/高亮，深色另需 `html.dark` 适配 |
| `stores/app.ts`（Pinia）已有 `leftCollapsed` 等布局态                        | 可扩展承载 `theme` 状态                                  |
| `BbFilterRail` 底部 `.left-box__bottom` 已有 3 个图标位                      | 放主题切换器的最自然位置                                      |
| ⚠️ `BbFilterRail.vue` 有 1 处 inline `borderBottom: 2px solid #0065c0` | **硬编码需清**，否则多主题下不随动                               |

## 2. 机制设计

### 2.1 主题 = 一组 `--bb-*` 变量的作用域覆盖

```
:root { /* 默认主题 light-classic：现样式，作为基线不动 */ }
:root[data-theme='light-modern'] { /* 现代浅色：鲜亮主蓝、更大圆角、柔和阴影 */ }
:root[data-theme='teal']         { /* 青绿主题 */ }
:root[data-theme='dark']         { /* 深色主题 */ }
```

- 运行时在 `<html>` 元素设 `data-theme="<key>"`（默认 `light-classic`）。
- `light-classic` 不写覆盖块，即 **`:root` 原生即经典浅色**，保证不启用功能时零回归、前端基线截图不受影响。
- 各覆盖块**只声明与本主题相关的变量**（可少覆盖，未覆盖的继承默认）。

### 2.2 Element Plus 联动

- 基础联动：各 `[data-theme]` 块内同时覆盖 `--el-color-primary`（及其 `light-3/5/7/9`、`dark-2`）、`--el-bg-color` 系列，使按钮/输入/标签/分页等随主题。
- 深色主题 `dark`：
  - 方案 A（推荐，改动小）：在 `dark` 块手动覆盖 EP 关键 `--el-*`（bg/text/border/primary），本项目 EP 用法收敛，足够覆盖弹出的下拉/日历/弹窗。
  - 方案 B（后续增强）：引入 `element-plus/theme-chalk/dark/css-vars.css` + `html.dark` 类，全面切 EP 官方 dark 变量。需在 `package.json` 加依赖与 `main.ts` 条件引入。
  - 本次先走 **方案 A**，把 EP 深色覆盖纳入 `dark` 主题块；若出现个别 EP 组件色块不达预期，M1 内补 B。
- 其余浅色主题（modern/teal）EP 底色仍为白/浅，只需主色联动，无需 dark css。

### 2.3 状态、持久化与启动

- `stores/app.ts` 增：
  - `theme = ref<ThemeKey>('light-classic')`
  - `setTheme(key)`：更新 `theme` → 写 `localStorage['bb-theme']` → 设 `document.documentElement.dataset.theme`（`dark` 时同步切/去 `html.dark`）
  - 初始化 `theme`：读 `localStorage['bb-theme']`，非法值回退默认
- `index.html` `<head>` 顶部**内联脚本**：首帧即读 `localStorage['bb-theme']` 设 `data-theme`，**避免刷新闪白/闪默认**（FOUC）。
- `main.ts` bootstrap：`useAppStore()` 不变（store 初始化时已从 localStorage 应用）；叠加 `dark` 主题处理。
- 可选（**本次不做**）：跟随系统 `prefers-color-scheme` 自动、后端持久化主题偏好 —— 列为二期。

### 2.4 切换入口（UI）

- 位置：`BbFilterRail.vue` 左栏底部 `.left-box__bottom`，在现有 3 个图标旁**追加第 4 个主题图标**（`el-icon`，如 `<Monitor/>` 或 `<Brush/>`）。
- 交互：点击弹出 `el-dropdown`，列出内置主题（各带小色块/名称）；选中即 `app.setTheme(key)`。
- 半透明/收起态兼容：左栏收起时的展开按钮区不涉及，主题入口随左栏一起隐藏（与现有图标一致）。

### 2.5 硬编码清理

- `BbFilterRail.vue` inline `borderBottom: '2px solid #0065c0'` → 改为 `var(--bg-accent)` 或引入新 token `--bb-accent-border`，保证随主题。

## 3. 内置主题（首批 4 套）

| theme key       | 名称       | 主色        | 背景            | 圆角/阴影            | 备注           |
| --------------- | -------- | --------- | ------------- | ---------------- | ------------ |
| `light-classic` | 经典浅色（默认） | `#0065c0` | 白 / `#faf9f8` | 6px / 扁平         | **现样式，0 回归** |
| `light-modern`  | 现代浅色     | `#1677ff` | 白 / `#f6f8fa` | 10-12px / 柔和分层阴影 | 鲜亮现代         |
| `teal`          | 青绿       | `#0ba5a0` | 白 / `#f2fbfa` | 8px / 轻阴影        | 清新           |
| `dark`          | 深色       | `#3b82f6` | `#14181f` 系   | 10px / 深阴影       | 夜间友好         |

> `light-classic` 为基线，**不因本功能改其数值**；其余主题在各自 `[data-theme]` 块覆盖 `--bb-*` 与 `--el-*`。

## 5. 验证

- `pnpm build`（含 `vue-tsc` 类型检查）通过。

- 单测：`appStore.setTheme` 持久化 & `data-theme` 应用（Vitest）。
