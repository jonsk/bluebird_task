## 采集规程（M0 执行）

1. **隔离环境**：在隔离区起「旧后端 + 种子数据 + 旧前端」；旧前端 `utils/request.js` 走真实旧接口。
2. **固定数据**：Playwright `page.route('**/api/**', route => route.fulfill({ json: <fixture> }))` 拦截旧接口，返回 `../fixtures/` 的**同一份** fixtures（跨新旧共享，见 `../fixtures/README.md`）。
3. **固定视口**：默认 `1440×900`；对关键组件（如 `BbTaskCard` 各态）额外导出组件级截图。
4. **导出清单**（`03 §2.3.2`）：六大视图列表、任务卡片（正常/逾期/临期/完成/收藏）、新增任务块、右侧详情抽屉、左栏（视图+分类树+组织树）、标签配置、日历、登录页、人员选择器、各下拉（日期/重复/提醒）。
5. **落库**：命名为 `<视图>-<状态>-<视口>.png`（如 `tasklist-normal-1440x900.png`），入库本目录并随 commit 版本化。
6. **录屏**：对交互密集项（完成任务失败回滚、移动任务、删除二次确认）补 `.webm` 录屏作为行为证据。
